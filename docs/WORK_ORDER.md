# 범용 Rough Z Tilt 확장 작업지시서

상태: 사용자 지시에 따라 개발·프린터 설치 보류. 이 저장소에는 작업지시서만
있다. Pandora2의 Klippain 의존성 제거 작업과 분리해서 진행한다.

## 목적과 범위

심하게 기울어진 베드에서 첫 외곽 측정까지 이동하지 못하는 문제를 줄인다.
기존 측정 삼각형을 중앙으로 축소해 러프 보정한 다음, 기존 전체 영역의
정밀 보정을 수행한다. 첫 단계의 목적은 최종 정밀도가 아니라 외곽 측정을
가능하게 만드는 것이다.

- Cartographer 전용 코드나 특정 프린터 크기·좌표를 넣지 않는다.
- TAP, BLTouch, 유도식 등 기본 Klipper Z tilt와 연동되는 자동 프로브
  인터페이스를 재사용한다. 프로브별 실제 검증 범위는 문서에 명시한다.
- `[z_tilt] points`를 읽고 `C + (P - C) * scale`로 축소한다.
- 기본 비율은 1/3. 중심은 설정/명령으로 지정하며 미지정이면 기존 점들의
  평균을 사용한다. 홈 위치 중심이 필요하면 해당 프린터 설정에서 지정한다.
- 실제 Z 모터 지지점 `z_positions`는 변경하지 않는다.
- 두 Z 모터의 두 측정점도 지원한다. 삼각형 세 점만 강제하지 않는다.

## 구현 방향

`rough_z_tilt.py`를 Klipper extras에 연결하는 독립적인 작은 확장으로 만든다.
기존 ZTilt의 계산·모터 제어 코드를 복제하거나 Klipper 본체를 패치하지 않는다.
축소 측정점으로 native Z tilt를 실행하고 원래 점을 반드시 복원한다.
구형/신형 Klipper의 프로브 결과 형식 차이는 native 처리에 맡긴다.

- `ROUGH_Z_TILT`: 축소 영역 러프 보정만 수행한다.
- `ROUGH_Z_TILT_PREVIEW`: 계산된 점을 출력한다. 홈·가열·프로브·이동 없음.
- native `Z_TILT_ADJUST` 및 기존 래퍼를 유지한다. 전체 순서는 프린터 매크로가
  `홈/프로브 준비 → ROUGH_Z_TILT → 전체 Z tilt → 필요 시 Z 재홈`으로 연결한다.
- `SCALE`, `CENTER`, 이동 높이·이동 속도 및 native 프로브 옵션 전달을 지원한다.
- 동기식 자동 프로빙만 지원한다. 대화형 `METHOD=manual`은 상태를 바꾸기 전에
  거절한다. 자동 도킹/온도 관리 정책은 기존 프린터 매크로가 담당한다.
- 성공·실패 모두 `finally`에서 원본 측정점과 이동 속도를 복원한다.
- 러프 단계만 끝났다고 `z_tilt.applied`가 참이 되지 않게 한다. 전체 정밀
  보정이 완료 상태를 결정한다.
- 0 미만, 0, 1 이상, NaN/Inf 비율과 잘못된 중심/점들을 거절한다.
- 실제 이동에는 XYZ 홈 상태가 필요하다. XY 오프셋 적용 여부를 존중해서
  native 측정 좌표를 해석하고, 축 이동 범위 밖의 노즐 좌표를 거절한다.
- 임의로 큰 기울기까지 충돌을 방지한다고 보장하지 않는다. 첫 XY 홈 경로의
  충돌 문제와는 별도 기능이다. 큰 실제 보정량 자체를 작은 값으로 강제해
  러프 보정을 무력화하지 않는다.

## 검증과 산출물

먼저 테스트를 작성하고 누락된 기능 때문에 실패함을 확인한다. 이후 구현한다.

1. 여러 크기와 원점 이동에 대한 동일한 축소 비율, 1/3 계산, 원본 불변성.
2. 두 점/세 점/여러 점, 프로브 XY 오프셋 및 기하학적 예외.
3. 프로브 오류·재시도 실패 시 좌표·속도 복원과 완료 상태 초기화.
4. 미홈/수동 모드 거부 및 preview의 무이동 검증.
5. 실제 Klipper 0.12와 현재 버전의 native helper로 오프라인 통합 검증.
6. 범용 예제, Klippain 등 기존 래퍼에 넣는 예제, 설치·업데이트·제거 설명.
7. Python 표준 라이브러리만 추가 사용하고 MCU 펌웨어 변경은 요구하지 않는다.
8. 사용자와 함께 첫 실기 테스트: 중앙 러프 → 전체 정밀 → Z 재홈.

설정 변경 전 사용자 변경을 구분하고 보존한다. Trident 설정을 변경할 때는
`/home/korellas/printer_data/config`의 규칙에 따라 검증 후 로컬 Git에 커밋한다.
프린터의 비밀키·사설 설정은 이 공개 저장소에 올리지 않는다.
